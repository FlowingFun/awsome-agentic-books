# Repository instructions

## Edit the sources, not the build output

- Edit the library homepages in [`site/index.html`](site/index.html) and [`site/zh.html`](site/zh.html). Keep equivalent changes in both languages; English is the default. Preserve `#mage-progress` on both pages because the builder fills it in.
- Edit the full article directories in [`site/articles.html`](site/articles.html) and [`site/articles-zh.html`](site/articles-zh.html). Keep topics and membership aligned across languages. The directories contain the complete list; the homepages show a 4–6 article selection in a single column on mobile. When changing a featured article, keep its summary and edition links in sync with the directory. Do not add search or pagination unless requested.
- Use [`site/library.css`](site/library.css) for library pages and [`site/styles.css`](site/styles.css) for shared reading-page styles. Use relative internal links so the site works both locally and under the GitHub Pages project path. Keep both README editions in sync when changing documented behavior.
- `_site/` is generated by [`tools/build_site.py`](tools/build_site.py). Do not edit or commit it. Keep upstream snapshots under `books/*/source/` unchanged during ordinary translation edits.

## Translations and sources

- Put translated text in the corresponding `books/*/zh/` JSON files. For MAGE, run `python3 tools/mage_text.py books/mage/source/index.html` (substitute the source page you are editing) to obtain the segment IDs and inline markers. Keep the IDs and paired `⟦ID⟧` / `⟦/ID⟧` markers intact; move whole pairs as needed for natural Chinese word order.
- Preserve the source’s code, formulas, diagrams and images, chapter hierarchy, anchor IDs, and bibliographic attribution. Translate surrounding prose and captions, not text embedded in original images. Do not label an incomplete translation as complete.
- Preserve original links and copyright notices. For outside material without confirmed redistribution permission, use a short original summary and a link to the source or official translation rather than republishing the text.

## Build and verify

- Install dependencies with `python3 -m pip install -r requirements.txt` in a virtual environment. For site or translation changes, run `python3 tools/build_site.py --output _site` from the repository root. Do not bypass the build’s checks for source integrity, translation coverage, protected content, or internal links.
- For navigation or catalogue changes, check both languages and the affected source/translation links. For layout changes, preserve readable narrow-screen layouts and usable language and navigation controls.
- Pushing to `main` triggers [the GitHub Pages workflow](.github/workflows/pages.yml) and updates the public site. Do not push or deploy unless requested.
